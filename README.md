# 🌿 Terraform: Genesis of Eden

> **Инкрементальная браузерная игра (Idle/Clicker) с эволюцией живого пейзажа и P2P-мультиплеером.**  
> Полностью статическая архитектура — запускается прямо на **GitHub Pages** без необходимости собственного сервера!

## 🎮 Особенности Игры

### 1. 🌄 Живой процедурный пейзаж
* Пейзаж на холсте Canvas 2D визуально эволюционирует от ваших кликов и улучшений:
  * **0% (Пустошь):** Серые безжизненные скалы, тусклое небо и космическая пыль.
  * **20% (Пробуждение):** Первые дожди, мох, конденсация атмосферы.
  * **45% (Оазис):** Лазурные озера, журчащие ручьи, луга с полевыми цветами и порхающими светлячками.
  * **70% (Великий Лес):** Вековые сосны и дубы, птицы в небе, смена дня и ночи.
  * **100% (Райский Эдем):** Северные сияния (Aurora Borealis), небесная гармония и открытие Вознесения.

### 2. ⚡ Синглплеер и развитие
* **4 сферы природы:** ☀️ Небо (клики и криты), 💧 Гидросфера (пассивный доход), 🌲 Биосфера (синергии и леса), 🔮 Гармония (глобальные умножители).
* **Система Престижа («Вознесение Эдема»):** Сброс прогресса в обмен на постоянный множитель к доходам (+25% за каждое вознесение).
* **Автосохранение и оффлайн-доход:** Прогресс сохраняется в `localStorage`, а при возвращении начисляется оффлайн-награда.

### 3. 🌐 Мультиплеер без сервера (WebRTC / PeerJS)
* **🌿 Кооператив (Co-op):**
  * Совместное терраформирование одной планеты.
  * Общая казна, клики напарника отображаются в реальном времени.
  * **Синхронное Цветение:** При одновременных кликах обоих игроков запускается буст х3!
* **⚔️ PvP Дуэль (Гонка Биосфер):**
  * Гонка до 100% терраформирования на раздельном индикаторе.
  * **Катаклизмы (Саботаж):**
    * 🌪️ *Песчаная буря* — снижает доход соперника на 70% на 8 сек.
    * ☀️ *Засуха* — замораживает доход, пока противник не кликнет 8 раз для полива.
    * ☄️ *Метеоритный дождь* — запускает падающий метеорит, который соперник должен успеть сбить кликом!

### 4. 🎶 Процедурный синтезатор Web Audio
* Музыкальные пентатонические переливы на кликах, звуки капель воды, шелест ветра и сигналы катаклизмов генерируются прямо в браузере через Web Audio API.

## 🚀 Как запустить на GitHub Pages (`github.io`)

### Шаг 1: Инициализируйте Git и создайте репозиторий
В терминале проекта выполните:
```bash
git add .
git commit -m "feat: Initial release of Terraform Eden game"
```

Создайте публичный репозиторий на [GitHub](https://github.com/new) (например, `terraform-eden`), свяжите его и отправьте код:
```bash
git branch -M main
git remote add origin https://github.com/ВАШ_НИКНЕЙМ/terraform-eden.git
git push -u origin main
```

*(Или через GitHub CLI: `gh repo create terraform-eden --public --source=. --push`)*

### Шаг 2: Включите GitHub Pages
1. Перейдите в ваш репозиторий на GitHub: `Settings` $\rightarrow$ `Pages` (в левой колонке).
2. В секции **Build and deployment**:
   * **Source:** выберите `GitHub Actions` (проект уже содержит `.github/workflows/deploy.yml` для автоматической сборки).
   * *Либо:* выберите `Deploy from a branch`, выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
3. Через 1–2 минуты ваша игра станет доступна по адресу:  
   👉 **`https://ВАШ_НИКНЕЙМ.github.io/terraform-eden/`**

## 🛠 Локальный запуск
Для локального тестирования достаточно любого локального HTTP-сервера (чтобы работали ES-модули):

* С помощью **Python**:
  ```bash
  python -m http.server 8000
  ```
* С помощью **Node.js** (npx):
  ```bash
  npx serve .
  ```
Затем откройте в браузере: `http://localhost:8000`
